# Setup Guide — Running This Project on Another Computer

Follow this from top to bottom on the new machine. Every command here was
tested on a clean Windows 11 setup.

---

## 0. First, understand what you are moving

This project is **three programs**, not one. They can be run separately.

| # | Part | What it is | Port | Needs |
|---|---|---|---|---|
| 1 | **Console app** | `com.hostel.main.Main` — the full menu-driven system | – | Java + MySQL |
| 2 | **REST API server** | `com.hostel.server.ApiServer` — serves JSON to the browser | 8080 | Java + MySQL |
| 3 | **React frontend** | `hostel-frontend/` — the web interface | 5173 | Node.js + parts 1–2 |

**Part 1 works completely on its own.** Parts 2 and 3 are the web version of
the same system — the frontend talks to the API, and the API reuses exactly
the same `service` and `dao` classes as the console app.

So decide what you need:

* **Console demo only** → do steps 1–7. Skip Node.js entirely.
* **Web version too** → do all steps.

---

## 1. Copy the project across

Copy the whole `HostelRoomAllocationSystem` folder, but **leave out two
folders** — they are generated and would waste most of your USB stick:

| Folder | Copy it? | Why |
|---|---|---|
| `src/`, `database/`, `docs/`, `lib/`, `*.bat`, `README.md` | **YES** | the actual project |
| `hostel-frontend/` (src, public, package.json, .env, vite.config.js) | YES, if you want the web version | |
| `bin/` | no | regenerated by `compile.bat` |
| `hostel-frontend/node_modules/` | no *(see §8 if offline)* | 68 MB, reinstalled by npm |

Without those two folders the project is about **3 MB**. With them, 72 MB.

> **Do not forget `lib/mysql-connector-j-26.7.0.jar`.** That is the MySQL
> driver. It is only 2.5 MB and it saves you a download on the new machine.
> If you copy via git, it is already tracked and comes along automatically.

---

## 2. Install Java

Install a **JDK 17 or newer** (this project was built and tested on JDK 21).
<https://adoptium.net/> is the easiest — pick "Temurin 21 (LTS)", and during
setup make sure **"Set JAVA_HOME"** and **"Add to PATH"** are enabled.

Verify in a **new** Command Prompt:

```bash
java -version
```

```bash
javac -version
```

**Both must work.** If `java` works but `javac` does not, you installed a
JRE, not a JDK — reinstall the JDK.

---

## 3. Install MySQL Server

Download **MySQL Installer for Windows** from
<https://dev.mysql.com/downloads/installer/> and install **MySQL Server 8.0**.

During configuration:

| Setting | Choose |
|---|---|
| Config Type | Development Computer |
| Port | **3306** (leave it) |
| Authentication | Use Strong Password Encryption (default) |
| Root password | **anything — but write it down** |
| Windows Service | leave ticked, start automatically |

MySQL Workbench is optional — it is only a GUI. The database itself is the
Server.

Verify the service is running:

```bash
powershell -Command "Get-Service MySQL80"
```

Status must say **Running**. If it says Stopped:

```bash
powershell -Command "Start-Service MySQL80"
```

---

## 4. Create the database

### Easiest way

Double-click **`setup-database.bat`** in the project folder. It finds
`mysql.exe` by itself, asks you to type `YES`, then asks for your MySQL
password.

> It **drops and recreates** `hostel_management`. On a new machine that
> database does not exist yet, so nothing can be lost. Only re-run it later
> if you want to wipe your data back to the sample data.

### If that fails — use MySQL Workbench

1. Open Workbench and click your `Local instance MySQL80` connection
2. **File → Open SQL Script** → choose `database\schema.sql`
3. Click the **⚡ lightning bolt** to run it
4. Right-click in the SCHEMAS panel → Refresh All

### Either way, check it worked

`hostel_management` should now contain **8 tables**: `admins`, `students`,
`hostel_blocks`, `rooms`, `allocations`, `complaints`, `hostel_fees`,
`waiting_list` — plus sample data (2 admins, 5 students, 3 blocks, 7 rooms).

---

## 5. Point the code at the new database ⚠️

**This is the step people forget.** Open:

```
src\com\hostel\util\DBConnection.java
```

and edit the block at the top:

```java
private static final String HOST = "localhost";
private static final String PORT = "3306";
private static final String DATABASE = "hostel_management";

private static final String USERNAME = "root";
private static final String PASSWORD = "admin123";   // <-- YOUR password
```

On most machines only `PASSWORD` needs changing. Change `PORT` too if you
did not use 3306.

Leave the `URL` line below it alone. It already contains the two settings
MySQL 8 requires (`sslMode=DISABLED` and `allowPublicKeyRetrieval=true`) —
see §9 for what happens without them.

---

## 6. Compile

Double-click **`compile.bat`**, or from the project folder:

```bash
javac -d bin -cp "lib\*" -sourcepath src src\com\hostel\main\Main.java src\com\hostel\server\ApiServer.java src\com\hostel\main\ConceptDemo.java
```

You should see **59 class files** appear in `bin\`. Any error here is a Java
problem, not a database problem — the database is not touched during
compilation.

---

## 7. Run the console application

Double-click **`run.bat`**, or:

```bash
java -ea -cp "bin;lib\*" com.hostel.main.Main
```

Log in with:

```
username : admin
password : admin123
```

(That is the *application* login from the `admins` table — it has nothing to
do with your MySQL password.)

Choose **2. Test database connection** first. You should see:

```
Connected to database : hostel_management
MySQL server version  : 8.0.46
```

If that works, everything is set up. **You are done** unless you want the
web version.

---

## 8. Optional — the web version

### 8a. Install Node.js

Only needed for the React frontend. Install **Node.js 20.19+ or 22.12+**
from <https://nodejs.org/> (the LTS build). Verify:

```bash
node --version
```

```bash
npm --version
```

### 8b. Install the frontend dependencies

```bash
cd hostel-frontend
```

```bash
npm install
```

This downloads about 68 MB and **needs an internet connection**. It takes a
few minutes the first time only.

> **No internet on the new machine?** Two options:
> 1. Copy the `node_modules` folder across on the USB stick as well — then
>    skip `npm install` entirely.
> 2. Or skip the dev server and serve the prebuilt `hostel-frontend\dist\`
>    folder, which is already compiled and only 357 KB.

### 8c. Check the API address

Open `hostel-frontend\.env`:

```
VITE_API_BASE_URL=http://localhost:8080/api
```

Leave this alone if the API runs on the same computer. Only change it if you
run the API on a different machine on the network.

### 8d. Run both parts — you need TWO windows

**Window 1** — double-click `run-api.bat`, or:

```bash
java -cp "bin;lib\*" com.hostel.server.ApiServer
```

Leave it open. It prints the endpoint list and waits on port 8080.

**Window 2** — double-click `run-frontend.bat`, or:

```bash
cd hostel-frontend
```

```bash
npm run dev
```

Then open the URL it prints — usually **<http://localhost:5173>**.

> If every page in the browser shows a connection error, the API window is
> not running. The frontend cannot reach the database by itself; it only
> talks to the Java API.

## 9. Troubleshooting

### `Public Key Retrieval is not allowed`

The single most confusing MySQL 8 error, and the one most likely to hit you
on a fresh machine.

**Cause:** MySQL 8 logs users in with `caching_sha2_password`. The *first*
time an account connects after the MySQL service starts, the driver must
encrypt your password with the server's RSA public key — so it has to
download that key. For safety the driver refuses to do that by default.

**Fix:** the JDBC URL in `DBConnection.java` must contain
`allowPublicKeyRetrieval=true`. It already does. If you rewrote that line,
put it back:

```java
"jdbc:mysql://localhost:3306/hostel_management?sslMode=DISABLED&allowPublicKeyRetrieval=true"
```

This error is sneaky because the program can work for days and then fail
after a reboot — the server's password cache is cleared when MySQL restarts.

### `No suitable driver found for jdbc:mysql://...`

The connector jar is missing from the classpath. Check that
`lib\mysql-connector-j-*.jar` exists, and that you ran with
`-cp "bin;lib\*"` and not just `-cp bin`.

### `Access denied for user 'root'@'localhost'`

The `PASSWORD` in `DBConnection.java` does not match your MySQL password.
Recompile after changing it — editing the `.java` file alone is not enough.

### `Unknown database 'hostel_management'`

You have not run `database\schema.sql` yet. Go back to step 4.

### `Communications link failure`

The MySQL service is not running:

```bash
powershell -Command "Start-Service MySQL80"
```

### `Address already in use: bind` (API server)

Port 8080 is taken — usually by an API server you already started and
forgot. Find and stop it:

```bash
powershell -Command "Get-NetTCPConnection -LocalPort 8080 -State Listen | Select-Object OwningProcess"
```

### `javac is not recognized`

The JDK is not on your PATH. Reinstall it with "Add to PATH" ticked, and
open a **new** Command Prompt afterwards — an open one keeps the old PATH.

### Frontend shows connection errors on every page

`run-api.bat` is not running, or `.env` points at the wrong address. Test the
API directly in a browser: <http://localhost:8080/api/dashboard> should
return JSON.

### Assertions never fire

You forgot `-ea`. Without it, every `assert` line is skipped.

## 10. Final checklist

Tick these off on the new machine:

- [ ] `java -version` and `javac -version` both work
- [ ] `Get-Service MySQL80` says **Running**
- [ ] `hostel_management` exists with **8 tables** and sample data
- [ ] `PASSWORD` in `DBConnection.java` matches the new MySQL password
- [ ] `lib\` contains `mysql-connector-j-*.jar`
- [ ] `compile.bat` finishes with no errors (59 class files in `bin\`)
- [ ] Console app menu option **2** prints "Connected to database"
- [ ] Login with `admin` / `admin123` works
- [ ] *(web only)* `node --version` works
- [ ] *(web only)* `npm install` completed in `hostel-frontend`
- [ ] *(web only)* API window running, browser opens at `localhost:5173`

---

## 11. The three ports, summarised

| Port | Used by | Started how |
|---|---|---|
| 3306 | MySQL Server | Windows service, automatic |
| 8080 | Java REST API | `run-api.bat` |
| 5173 | React dev server | `run-frontend.bat` |

If any of these is already in use by other software, you will get a "bind"
or "address in use" error. The MySQL port is set during installation; the
API port is `PORT` in `ApiServer.java`; the Vite port can be changed in
`hostel-frontend/vite.config.js`.
